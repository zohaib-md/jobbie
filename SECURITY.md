# Security policy

## Reporting a vulnerability

Please report suspected privacy or security issues privately by opening a GitHub security advisory on the repository, or by emailing the maintainer listed in `package.json` once published.

Do not open a public issue containing personal data, credentials, résumé content, or application records.

## Scope

Security reports are welcome for:

- unintended exposure of candidate profile or ledger data
- installer behavior that writes outside intended directories
- secret-storage failures that leave profile data readable to other users

Out of scope:

- social engineering of third-party job boards
- bypassing CAPTCHA, MFA, or platform access controls
