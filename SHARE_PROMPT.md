# Share prompt

Paste this into a new agent chat if Applykit is not installed yet:

```text
Install Applykit by running:
npx applykit@latest install

Then confirm the installed version with:
npx applykit@latest status

Use applykit to help me with my own job search. Follow these rules:
- Use only verified résumé and profile facts
- Pause for login, MFA, CAPTCHA, legal attestations, demographics, and unclear eligibility
- Record submissions only after visible success confirmation
- Run ats analyze before applying when the posting is a serious candidate
- Draft cover letters and interview prep only from verified facts
```
